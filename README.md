# مدرسة سوريا الغد - Syria Al-Ghad School

الموقع الرسمي لمدرسة سوريا الغد. موقع تعريفي يقدم معلومات عن المدرسة، البرامج التعليمية، الخدمات الإلكترونية، والأخبار والفعاليات.

The official website for Syria Al-Ghad School. An informative site presenting the school, educational programs, electronic services, and news & events.

## 🛠️ Tech Stack / التقنيات المستخدمة

- **HTML5** — بناء الصفحة / Page structure
- **CSS3** — التصميم والتنسيق / Styling
- **JavaScript** — التفاعل / Interactivity
- **Bootstrap 5** — إطار عمل CSS / CSS framework
- **Font Awesome** — الأيقونات / Icons
- **Google Fonts (Cairo)** — الخطوط / Fonts

## 📁 Project Structure / هيكل المشروع

```
surya/
├── index.html      # الصفحة الرئيسية / Main page
├── style.css       # التنسيقات / Styles
├── main.js         # السكربتات / Scripts
├── .gitignore
├── README.md
└── img/            # الصور / Images
```

## 🚀 How to Run / طريقة التشغيل

1. افتح ملف `index.html` في المتصفح.
2. Open the `index.html` file in your browser.
